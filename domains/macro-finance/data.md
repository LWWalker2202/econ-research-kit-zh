# 宏观与金融：数据

## 数据来源

中国宏观金融实证的数据景观由三类来源构成：转售官方与市场序列的商业聚合商、定义概念口径的官方统计发布，以及能够构建利差与杠杆的证券层面记录。三类都不完整，一篇论文通常要把它们拼接起来，所以第一件实务工作是判定每个概念以哪个来源为准，并把拼接过程留在复现包里。

商业终端是多数研究的起点。Wind 金融终端提供货币市场利率、国债与政策性金融债收益率、信用债收益率、发行层面信息以及大批宏观序列；CSMAR 覆盖上市公司、其财务报表，以及企业层面研究用到的债券与贷款数据的大部分。便利有代价：序列会被修订，债券市场覆盖随发行规则变化，标识体系跨期不稳定，因此每个序列的提取日期与版本口径都应记录在案。

官方统计定义的是论文将要被对照检验的概念。中国人民银行发布货币供应量、社会融资规模，以及为工具定日的政策文件；财政部发布财政收支与地方政府债务余额；国家统计局发布产出、投资、价格与住房指标。概念变化是主要风险：社会融资的覆盖范围、地方债务的处理方式、房价指数的定义，在样本期内都至少修订过一次，忽略概念变化的存量序列会把修订解释成经济变化。

证券层面数据让利差与杠杆可测。债券募集说明书、发行文件与评级报告给出票面、期限、担保、发行人行业与评级；匹配同期限国债或政策性金融债收益率即可得到利差基准。评级下调与违约或重组事件必须按公告定日，而不能用供应商的当前状态字段，因为当前字段会覆盖历史。城市房价方面，商业城市指数在覆盖范围与新房二手房处理上各不相同；官方指数覆盖较窄但口径更可查。

## 变量与口径

| 变量（英文原词） | 定义 | 来源 |
|---|---|---|
| 政策利率代理变量 | 用以代表政策立场的短期货币市场或便利工具利率，并说明是哪件工具 | 央行操作公告、Wind |
| 银行间质押式回购利率 | 七天期质押式回购利率，用作市场隐含的资金成本 | Wind、CSMAR |
| 中期借贷便利利率 | 央行中期借贷便利的利率，用作政策价格 | 央行公告、Wind |
| 贷款市场报价利率 | 报价制贷款基准利率，定价改革后生效 | 央行、Wind |
| 基准存款利率 | 管制的一年期存款利率，改革前的政策价格 | 央行、Wind |
| 信用利差 | 企业债或地方债收益率减去同期限国债收益率 | Wind、债券发行记录 |
| 杠杆率 | 负债比资产或负债比产出，并明确分子定义 | CSMAR、央行资金流量表 |
| 社会融资规模 | 对实体经济的融资总量，存量与增量两个口径 | 央行统计 |
| 地方政府债务 | 官方认定的地方政府债务，与融资平台负债分别统计 | 财政部、Wind、评级报告 |
| 经济政策不确定性指数 | 基于文本的政策不确定性指数，并记录所用报纸集合 | 已发布指数，或依来源重建 |
| 城市房价 | 城市层面商业或官方价格指数，并说明新房或二手房口径 | 国家统计局、商业数据库 |

## 已知问题

- 供应商不对序列做版本管理：今天提取的数据无法复现两年前做的表，除非当初记录了提取日期。
- 政策利率代理变量在样本内更换身份，一条拼接序列内嵌着制度断裂。
- 债券覆盖在发行稀少处被截断，市场扩容前的截面样本存在选择性问题。
- 评级与违约状态字段是当前值的快照，不是历史值；事件必须按公告定日。
- 地方政府债务至少有两个公开发布的定义——认定债务与平台负债，两者不可互换。
- 社会融资包含覆盖范围曾变化的成分，跨修订使用存量序列会把修订解释成政策效果。
- 城市房价指数在新房、二手房与行政区划处理上各不相同。
- 财政与债务数据存在发布滞后与偶发重述，应写明所用数据版本。
- 省级加总数据与企业层面数据需要显式的加权选择，而这个选择会改变估计结果。
