# 宏观与金融：制度背景

## 制度背景

宏观金融实证研究的可信变异大多来自政策，而政策本身是对经济状况的回应。本文件交代中国这一反馈回路格外直接的制度场景：央行同期并行使用基准利率体系与多种中短期借贷便利，地方政府支出大量通过表外融资平台完成，银行信用中介反复从贷款科目迁移到表外。目的不是判定什么算外生，而是让读者看清论文用的究竟是哪种政策变异。

货币政策操作在两个时点发生了对识别有意义的变化。2010年代中期以前，主要操作目标是存贷款基准利率，以离散方式调整，信贷额度与准备金率等数量工具承担主要调节，银行间利率更像结果而非工具。2013年起，常备借贷便利、中期借贷便利（MLF）与常态化的公开市场操作陆续加入，流动性管理和银行资金成本开始在边际上被调节。2019年贷款市场报价利率（LPR）改革，把报价改为以MLF为锚的报价机制，等于在原有体系上又加了一层更有相机色彩的定价层。跨这两种制度拼出的“政策利率”序列本身是构造物，取哪个代理变量决定样本断点；把某个市场利率当作政策立场的论文须说明它代表哪件工具。

财政政策是地方政府行为进入识别问题的地方。2008年大规模刺激后，地方基础设施融资转向地方政府融资平台（LGFV），平台以政府名义举债，出现在信用数据里却不在预算内。2014年预算法修订及随后的债务置换，把一部分存量搬进官方认定的地方政府债务，2017年以后的监管周期又收紧了对隐性债务的处理。因此，通过基础设施投资识别出的财政冲击，同时是信用供给冲击与对债务认定的预期冲击。土地财政方向相反：商品房销售为地方预算提供资金，房地产政策也是一种财政工具。

影子银行与资产管理补上最后一块。贷款额度或资本监管构成约束时，资金经银行理财、信托贷款和委托贷款绕行；约束放松时回流表内。2018年的资管新规对各类产品施加统一约束，触发了一轮可见的表外收缩。社会融资规模因此常被用作实证对象，但其构成在样本期内变化很大，存量与构成序列支撑不同的故事。

汇率与资本项目管理构成第四个板块。2000年代中期汇改把人民币转入有管理浮动，2015年中间价调整后跨境资金流动管理加强，货币篮子参考又让每日中间价带有相机色彩。在此背景下用公告识别货币冲击，须处理汇率与利率工具常同时使用、在岸离岸价格可能背离两件事。

为什么这对识别重要：本领域的处理变量通常是政策事件或政策立场，而不是个体受到的处理。于是政策反应函数成为头号威胁。选设计之前，论文应能回答三件事：没有这个冲击时政策本会怎么做、哪件工具承载冲击、哪个部门或地区对冲击的暴露程度有差异。经得起审稿的设计多半是：公告日的窄事件窗口、前期清晰可辨的制度断裂、或在冲击之前已测度的截面暴露程度；用总量结果反推冲击时点的论文多会被要求重做。

## 时间线

| 年份 | 事件 | 对研究的意义 |
|---|---|---|
| 2008 | 宣布大规模刺激计划 | 财政冲击有明确公告日，地区暴露程度可异质 |
| 2013 | 常备借贷便利与流动性操作常态化 | 从基准利率管理转向便利工具管理流动性的起点 |
| 2014 | 推出中期借贷便利 | 出现第二个政策价格，可区分资金成本冲击与数量冲击 |
| 2015 | 预算法修订与地方债务置换 | 地方债务被正式认定的制度变化，支持前后对比设计 |
| 2015 | 中间价形成机制调整 | 有确切日期的汇率制度变化，离岸在岸价差可观测 |
| 2017 | 收紧隐性债务监管 | 按省份分批、强度不一，可用于暴露程度设计 |
| 2018 | 发布资管新规 | 对产品施加统一约束，表外信用收缩 |
| 2019 | 贷款市场报价利率改革 | 定价机制变化，改变了从政策利率到贷款利率的映射 |
| 2020 | 疫情时期宽松与财政扩张 | 需求、供给与政策同时受冲击，很少是干净实验 |

## 可直接引用的段落

识别策略前需要制度背景时可改写这两段；引用照原样保留。

这一时期中国的货币政策在逐步市场化的价格工具与仍然活跃的数量工具之间并行。存贷款基准利率被管制并以离散方式调整，直到2019年贷款市场报价利率改革；流动性与银行资金成本自2010年代中期起通过常备借贷便利与公开市场操作管理。其结果是，任何用作政策立场代理变量的序列都内含一项判断：作者认为哪件工具实际发挥作用。论文应明说这项判断，而不是藏在变量名里。

地方借债先后经过三个部分重叠的制度阶段：2008年刺激后经融资平台借债，预算法修订后一部分存量被认定并置换为正式债务，2017年后对隐性债务的处理不断收紧。由于阶段在时间上重叠，标注“地方政府债务”的虚拟变量在同一个样本内可能改变含义；跨阶段的存量序列则把度量变化与经济变化混在一起。
