# 理论建模与机制设计：制度背景

理论论文的制度部分不是政策史，而是给假设清单出庭作证：谁掌握信息、谁先动、谁能承诺。审稿人找的是论文离不开的那条假设，以及给它背书的制度是否真的成立。以下记录最常被借用的制度与其时点。

## 制度背景

**信息：谁知道什么。** 中央在报告链条顶端，企业与住户的细信息在地方；环境监测长期由地方生产、向上报送，事权上收的正当性正是"地方有信息、中央难核实"〔核〕。统计同理：地方采集、对照考核、逐级汇总。甄别假设因此须点明谁缺信号、哪项制度没把信号传上去。

**时序：谁先动。** 中央先定分税规则、土地指标与环境目标，地方再选执行强度；地方对企业在产业政策与土地供给上同样是领导者。平台与金融监管常反过来，规则在市场做大后才到，故"进入前承诺"与"进入后反应"两类结论不同。时序假设站得住的前提，是指出工具、持有者与设定时点。

**承诺：哪些承诺可信。** 产权与合同受法律保护、由法院执行；政策连续性则受制于地方官员的有限任期与保留的裁量权。承诺有的因交给规则而可信，有的因反转代价高，有的完全不可信，假定最后一类应视为上界。隐性担保靠信念而非成文法，模型须解释信念何以维持。

**产权与要素配置：简化区。** 城市土地国有、农村土地集体所有，土地供给由地方行政配置；国企承担政策性负担、预算约束更软；资本配置受所有制与信贷额度影响；劳动按户籍分割；若干能源价格仍受管制。完全市场与代表性住户在此是简化，论文应说明它换来了什么。

下表是审稿人期待看到的声明清单，右列应在投稿前填好。

| 假设 | 制度地位 | 论文怎么处理 |
|---|---|---|
| 上层只观测到粗信号 | 制度事实 | 点明报送机构与核实难题 |
| 中央先承诺、地方后执行 | 半事实半简化 | 引规则固定顺序，讨论反转 |
| 完全承诺 | 简化，上界 | 声明为上界，报去掉后的变化 |
| 完全无摩擦信贷市场 | 简化，与信贷实践相悖 | 加借贷约束或讨论偏误方向 |
| 竞争性要素市场出清 | 对土地资本能源均为简化 | 显式处理管制价格 |
| 代表性住户 | 掩盖户籍分割 | 讨论异质性或给出总量上界 |
| 单期或两期时限 | 对政策周期为简化 | 论证时限或说明结果不敏感 |

## 可直接引用的段落

中国的财政与行政结构把中央放在层级顶端，企业与住户的大量信息却掌握在地方手中。统计由地方采集、对照考核、逐级汇总，政绩考核塑造报送激励；环境监测事权上收前亦然〔核〕。"上层只有粗信号、下层有细信号"的模型因此描述的是报告关系，而非随意设定的信息技术。同一结构定住时序：中央先宣布分税规则与土地指标，地方再定执行力度。是否真有约束力是实证问题，本文处理为〔待填〕。

产权与合同受法律保护、由法院执行，政策连续性则受制于地方官员的有限任期与保留的裁量权。承诺有的因交给规则而可信，有的因反转代价高，有的只因当事人相信会被履行；地方融资平台隐性担保属最后一类。完全承诺是上界，无承诺是下界。本文〔待填〕，并写明什么证据会让该假设朝任一端移动。
