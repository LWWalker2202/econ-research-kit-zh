# 健康经济学：数据

## 数据来源

中国的健康数据分四层：人群面板调查、行政医保记录、机构与生命统计、以及环境暴露数据。一篇可信的论文通常至少拼接其中两层，因为调查测的是人，行政记录测的是处理。

面板调查是个人结果变量的主要来源。中国健康与养老追踪调查（CHARLS）覆盖 45 岁及以上人群，收集健康、认知、保险与支出，并做体检测量。中国家庭追踪调查（CFPS）覆盖全年龄段、两年一期，健康与保险模块较细。中国健康与营养调查（CHNS）是长时段分省面板，营养、人体测量与生物标志物数据细。中国老年健康影响因素跟踪调查（CLHLS）聚焦高龄老人，是高龄死亡率与长寿结果的常用来源。

行政数据承载处理，有时也承载结果。县级医保经办机构掌握参保名册与报销方案；结算数据记录花了多少、报了多少；出院记录与按病种付费记录描述住院。中国卫生健康统计年鉴提供省级床位数、卫生人员数、门诊与住院人次、次均费用，足以控制供给能力，但不足以构造病人层面的处理。

生命统计与普查提供死亡率的背景。死因监测点提供部分县的死因数据，普查提供年龄结构与粗死亡率，全国死亡登记系统在观察期内逐步完善。暴露数据方面，监测站与卫星反演的污染估计可以匹配到县或栅格层面；规制一侧的构造与识别问题在 `domains/energy-env` 中处理，本文件只覆盖“暴露与健康”这条路径。

## 变量与口径

| 变量（英文原名） | 定义 | 来源 |
|---|---|---|
| insurance scheme | 受访者当年参加的险种，按险种类型编码 | CFPS、CHARLS、县级参保名册 |
| enrollment status | 受访者当年是否被任一险种覆盖 | 调查参保模块 |
| reimbursement rate | 受保医疗支出中报销部分的比例，用实现值而非名义值 | 结算数据、县级报销方案 |
| out-of-pocket spending | 家庭自付的医疗支出，总量与分服务类型 | 调查消费模块、结算 |
| total medical spending | 含报销部分的家庭医疗支出 | 调查与结算拼接 |
| self-rated health | 对总体健康的五点自评 | CFPS、CHARLS、CLHLS |
| ADL and IADL | 日常活动能力与工具性日常活动能力受限的项数 | CHARLS、CLHLS |
| chronic disease | 是否经医生诊断患有慢性病，按病种分 | CFPS、CHARLS、CHNS |
| BMI | 体重（千克）除以身高（米）的平方，用实测数据 | CHNS、CHARLS |
| CES-D score | 使用 CES-D 量表得到的抑郁症状得分 | CHARLS、CFPS `[待核实模块]` |
| outpatient visits | 参考期内门诊就诊次数 | 调查利用模块、结算 |
| hospitalization | 是否住院及住院次数 | 调查、医院记录 |
| death | 观察期内是否死亡及死亡日期 | 后续波次、生命登记 |
| pollution exposure | 居住地相关污染物的年均浓度 | 监测站、卫星反演 |

## 覆盖范围

| 数据 | 时期 | 层级 | 说明 |
|---|---|---|---|
| CHARLS | 2010 年代起的全国面板 | 个人、家户、社区 | 45 岁及以上；含体检测量 `[待核实波次]` |
| CFPS | 两年一期全国面板 | 个人、家户、社区 | 全年龄段；含健康与保险模块 `[待核实波次]` |
| CHNS | 长时段分省面板 | 个人、家户 | 人体测量与生物标志物 `[待核实波次]` |
| CLHLS | 多期高龄老人调查 | 个人 | 65 岁及以上，含死亡随访 `[待核实波次]` |
| 中国卫生健康统计年鉴 | 年度 | 省 | 床位、人员、服务量与次均费用 |
| 结算与出院数据 | 与事件相关 | 个人、机构 | 通常需要通过地方合作获取 |
| 死因监测点 | 年度 | 县 | 分死因死亡率，覆盖随时间改善 `[待核实]` |
| 普查与人口抽样调查 | 十年一次加抽样 | 省、县 | 年龄结构与死亡率分母 |

## 已知问题

- 死亡不是缺失值。受访者死亡后离开面板，而死亡恰好在最要紧的那些设计里与处理相关，存活样本因此是选择出来的。要分处理臂报告死亡与流失，并给出界估计。
- 健康模块的流失比收入模块更大，病人和老人流失更多。要比较流失者与留下者的基线特征，并按处理状态报告平衡性。
- 险种编码随每一期调查变化，因为制度本身在合并。跨波同名变量可能不是同一个东西，应当根据每一期的原始题目重建险种变量。
- 上报支出存在回忆误差，且各调查的回忆期不同。报销部分与自付部分的回忆准确度可能不同，偏误方向要论证，不能假定。
- 自报慢病同时反映患病与诊断。医保扩张改善了就医可及性，诊断率会上升，这与发病率无关；它是另一个边际上的真实效应，不应写成健康改善。
- 只有部分波次、部分子样本有体检测量。以实测 BMI 或血压为条件的分析，会悄悄丢掉没做体检的受访者。
- 机构层面数据只覆盖上报的医院，且上报门槛会变。比较住院量的时间序列时，必须检查上报面板。
- 监测站分布不均且偏城市。卫星反演能填满栅格但有噪声，两者都不是在户级测量的。
- 调查与行政医保记录拼接需要标识变量，公开数据通常已去除。若有拼接文件，要报告匹配率以及按处理状态的损失。
