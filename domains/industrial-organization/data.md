# 产业组织与规制：数据

## 数据来源

中国产业组织可用的数据环境是一堆各自不完整的总体，几乎每一个设计选择都取决于用哪一个总体。中国工业企业数据库（Chinese Industrial Enterprises Database, CIED）是主力的企业层面来源：它按年记录规模以上制造业企业的销售额、就业、资本、中间投入、所有制与四位行业代码。它不是、也从来不是全部企业的普查。样本门槛在 2010 年代初被提高过，这使得该年前后的样本构成发生变化〔待核实〕；而已在库内、后因跌破门槛而消失的企业，如果不重建面板，看上去就与退出无异。

中国海关数据库（China Customs Trade Database）提供企业层面与交易层面的进出口记录：产品代码、流向国、数量、金额、单价、贸易方式与企业标识。它对产业组织的价值在单价——这是可观测变量里最接近可贸易品成交价格的一个——以及能区分加工贸易与一般贸易，因为两者的定价逻辑不同。它的弱点是企业标识：与工业库的企业标识不是同一套，且会随企业登记状态变化而改变。

市场监管系统的工商登记记录覆盖全部登记在册的企业，而非超过某一门槛的企业：注册日期、注册资本、地址、行业、所有制类型、经营范围，以及注销或吊销日期。这是唯一能在没有规模截断的情况下度量进入与退出的来源。但登记是法律状态而非经营状态，空壳企业会让两者差距很大。

所有制数据来自国有资产监管系统与上市公司数据库。上市公司的规模与盈利能力强于工业调查平均水平，因此它们是研究会计数据算出的加价率的合适样本，却是研究市场结构的不合适样本。价格数据来自统计年鉴、价格主管部门的价格监测，以及可得的商业扫描数据；最后一种是唯一带有产品层面真实零售价格的来源，但它属于商业专有，且地区覆盖不全。开发区名录与并购案件公告是需要手工编码才能转成有日期的处理变量的行政文件。

## 变量与口径

| 变量（英文原名） | 定义 | 来源 |
|---|---|---|
| firm id | 数据源内部唯一的企业标识，跨源不可直接比较 | 工业库、海关库、工商登记 |
| industry code | 四位行业分类，跨年份会修订；必须重编码到同一版 | 工业库、工商登记 |
| sales revenue | 企业当年销售总额，名义元 | 工业库 |
| value added | 产出减中间投入；各年定义并不一致 | 工业库 |
| employment | 年末从业人员数 | 工业库 |
| capital stock | 固定资产原值或净值；两者不可互换 | 工业库 |
| intermediate inputs | 生产消耗的原材料、燃料与购买的服务 | 工业库 |
| exports value | 出口货物离岸价值，美元 | 海关库 |
| unit price | 进出口金额除以数量，美元单价 | 海关库 |
| trade regime | 加工贸易或一般贸易，属企业—产品—年份属性 | 海关库 |
| registered capital | 注册时认缴资本，元 | 工商登记 |
| registration and exit dates | 成立日期与注销或吊销日期 | 工商登记 |
| ownership type | 登记的所有制类别；上市公司则为实际控制人 | 工商登记、上市公司数据 |

## 覆盖范围

| 数据 | 年份 | 层级 | 样本量级 |
|---|---|---|---|
| 中国工业企业数据库（CIED） | 1990 年代末至 2010 年代初〔待核实〕 | 企业 | 每年约十万至数十万家〔待核实〕 |
| 中国海关数据库 | 2000 年代初起〔待核实〕 | 交易，可汇总到企业—产品 | 每年约百万至千万条记录〔待核实〕 |
| 工商登记 | 2000 年代起，电子化覆盖逐步提高〔待核实〕 | 企业 | 约千万家〔待核实〕 |
| 上市公司财务数据 | 1990 年代起 | 企业 | 约数千家〔待核实〕 |
| 价格监测与统计年鉴 | 各序列不一〔待核实〕 | 产品或城市 | 约数百个价格序列〔待核实〕 |
| 开发区名录与并购案件 | 开发区自 1984 年起，案件自 2008 年起〔待核实〕 | 开发区、案件 | 约数千个开发区与案件〔待核实〕 |

## 已知问题

- 工业库的规模门槛在样本期内变动过，因此企业数量的逐年变化同时反映覆盖变化与企业总体变化。在任何趋势结论之前，先报告逐年在库企业数与门槛规则。
- 从工业库中消失不等于退出。企业可能跌到门槛以下、未上报，或改变法律形式。用工商注销记录区分这三类，并报告“消失”中真正退出的比例。
- 增加值、资本与中间投入都是按现价填报的。用同一个指数平减三者，等于假设产出与投入的价格变动相同，这会系统性影响加价率估计；应分别使用产出与投入平减指数，并同时报告两套结果。
- 行业分类会修订，而修订日期并不与任何政策日期重合。把年份重编码到同一版之后，还要检查在企业受影响的那几年里，重编码是否把企业挪到了别的行业。
- 海关库的企业标识覆盖贸易型企业，包括没有生产能力的纯贸易中间商。不区分中间商就把海关库并入工业库，会把生产者和贸易商混进同一个加价率计算。
- 工商登记记录的是法律存在。登记过的企业可能从未经营，注销过的企业可能多年前就已停业。用登记日期度量的进入与退出，是经济意义上进入与退出的上界。
- 上市公司数据按规模与融资能力被选择过。用它算出的会计加价率，与用工业库生产函数算出的加价率不可直接比较。
- 并购案件清单只包含已申报案件，且公开字段随主管机关变化。跨 2018 年机构重组编码执法强度时，需要记录案件定义的变更，而不能假设定义连续。
