# 教育经济学：处理变量的构造

中国的教育研究多半围绕"队列"和"地方"两件事。一项改革只作用于某县某年级的孩子，研究者的任务是把这条规则变成能识别"谁被处理、何时被处理、强度多大"的变量。麻烦在于同一个变量——受教育年限——有好几种都站得住的折算方式，差别在于它们对职业教育、留级与各学段回报的假设不同。下面几张表列出文献里反复出现的定义、每种定义需要的假设，以及审稿人会否掉的构造方式。

## 处理变量怎么构造

| 处理变量定义 | 数据来源 | 隐含假设 | 什么时候用 |
|---|---|---|---|
| 扩招暴露度：出生队列与省级招生计划增幅的交互 | 招生计划公告、省级教育统计；出生年取自普查或调查 | 扩招不是针对其所改变结果的那些队列与省份，且没有别的政策作用于同一队列 | 教育回报、收入不平等、质量—数量权衡研究 |
| 撤并暴露度：受访者小学学龄期间本县被撤并的村小数量 | 县级教育统计与年鉴、省级布局调整文件 | 县内撤并时点不由受影响儿童的就学结果决定 | 学校可达性与学校资源对受教育年限的影响 |
| 免费义务教育暴露度：免费政策在该省落地时正处受处理年级的出生队列 | 省级免费政策文件与按年级的分批推进表 | 免费政策落地时没有伴随只作用于同一队列的其他变化 | 就学成本对入学率与完成率的影响 |
| 受教育年限：由最高完成学历折算的等价年数 | 住户调查或普查的学历变量 | 每一年教育对应一个恒定的人力资本增量 | 只能观测到学历层级时的教育回报估计 |
| 班级规模与生师比：学校或县级层面的度量 | 学校层级教育统计、县级年鉴 | 班级规模的变异与同班学生成绩无关 | 资源对学业表现的影响，且有校内变异可用 |

| 结果变量 | 需要写明的定义 | 定义选择会怎样改变估计 |
|---|---|---|
| 受教育年限（标准折算） | 小学 6 年、初中 3 年、高中 3 年、大学 4 年 | 把职业高中与普通高中视为等价，也忽略留级 |
| 受教育年限（分学段折算） | 各学段分年计，并对是否职业教育单设虚拟变量 | 允许回报按学段不同；每个单元格所需样本更大 |
| 最高学历 | 小学、初中、高中、大专及以上的分类虚拟变量 | 对折算误差稳健，但丢掉层级内部变异 |
| 入学率或升学率 | 某年龄队列在学比重，或初中毕业生升入高中的比重 | 分母口径不同会改变水平与趋势 |
| 班级规模 | 每班学生数，自报或取自学校记录 | 自报班级规模存在堆积与测量误差 |
| 生师比 | 学生数除以教师数，县级或校级 | 不同来源对是否含非教学人员的处理不同 |
| 生均支出 | 在校生人均经常性支出，实际值 | 资本性支出与教师工资拖欠不计入，且在县际不同 |
| 考试成绩 | 来自调查或行政测评的标准分 | 不同考试、不同年份的分数不经等值化不可比 |

## 各定义的识别假设

| 定义 | 必须成立什么 | 什么会推翻它 |
|---|---|---|
| 扩招暴露度 | 招生计划增长不是对队列规模或本省毕业生劳动力需求的回应 | 扩招瞄准回报正在上升的省份，或同期年轻劳动力出现迁移 |
| 撤并暴露度 | 撤并时点与该县儿童就学的未观测决定因素不相关 | 县因生源流失而撤并，而生源流失本身就反映外出务工 |
| 免费教育暴露度 | 免费是该省该队列唯一发生的变化 | 同期课程改革或教师招聘作用于同一队列 |
| 受教育年限 | 折算在各队列、各地区间恒定，且就学年限无系统测量误差 | 留级，或职教学历被按不同年数折算、且省际不同 |
| 班级规模 | 班级规模变异不由学生分组造成 | 家长把孩子转进小班，或学校把弱学生编入大班 |
| 考试成绩 | 测评在被比较的单位之间可比 | 不同试卷、不同年份、不同评分标准，或参与存在选择性 |

## 常见构造错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 把所有高中后教育折算成同样年数 | 低估职教回报、高估普高回报 | 报分学段回报，并对职教单设虚拟变量 |
| 把"高中"当成一个类别 | 混淆普高与中职学生，两者回报不同 | 按轨道拆分；动手前先确认拆分可得 |
| 用调查年份当改革年份 | 对多年后才被调查的队列赋错处理时点 | 按受访者在改革时所处年级赋处理 |
| 用县总人口做分母算暴露度 | 把撤并与人口迁移混在一起 | 用学校队列而非常住人口重建暴露度 |
| 不经等值化直接比较跨轮考试成绩 | 把测量变化读成学习变化 | 用轮内标准化分数，并报告等值化程序 |
| 忽视普查自报教育年限的堆积 | 舍入与堆积造成衰减偏误 | 用完成学历虚拟变量做稳健性，并报告堆积形态 |
