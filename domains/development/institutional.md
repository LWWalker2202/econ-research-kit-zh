# 发展经济学与田野调查：制度背景

在中国做发展经济学，研究对象很少是某一项全国统一的项目，而是一组由地方执行、地方认定资格、地方决定村庄名单的干预：谁有资格领低保、哪个村拿到项目、学校与卫生室设在哪里、农户能不能把承包地租出去。处理单位通常是县或村；数据的生产单位则是研究团队自己做的住户调查。这两点决定了能识别什么，也决定了审稿人会问什么。

## 制度背景

**扶贫与瞄准机制。** 城市居民最低生活保障制度在 20 世纪 90 年代末建立，作为地方财政负担的收入底线；农村低保在 2000 年代全国推开 `[待核实]`。2010 年代的脱贫攻坚在此之上加了贫困户行政登记、驻村工作队与干部按户结对的责任制。对研究最要紧的制度细节是资格由地方认定：同样的收入在一个县算贫困户、在邻县可能不算。因此，用县域门槛或农户资格做处理变量，测的是一个地方行政决定，而不是一条全国规则。

**县与村的行政边界变动。** 撤县设区把财政权、土地用途和公共服务责任从县上收到市里；合并村庄、撤并小规模学校则改变服务的供给地点和农户的通勤距离。这类事件有明确日期、地理分布不均，因此常被用作识别来源。

**土地权利。** 农村土地归集体所有。2010 年代的承包地确权登记把农户的承包权落在图册上，随后“三权分置”把所有权、承包权与经营权分开，使出租成为正式选项。研究用的变异通常来自各省各县确权进度的差异，结果变量多是有没有出租、有没有投资、有没有外出。

**公共服务。** 新型农村合作医疗在 2000 年代中期试点、随后全国推开；农村义务教育免除学杂费与教科书费也走过类似的分批推进路径。两者都可作为服务可及性冲击，执行强度县际差异大。2000 年代的撤点并校由村级学龄人口下降推动，它既是教育结果的处理，也是任何村级变量的混杂来源。

**信贷与数字金融。** 小额信贷试点让部分县获得贴息的小组贷款；基于支付平台数据构建的数字普惠金融指数提供县—年的金融服务可及性度量。前者带一条选择规则，后者是连续暴露指标，口径由编制方决定。

**易地搬迁。** 脱贫攻坚期间把生态脆弱区与深度贫困区的农户整村搬出，形成新的安置社区。它同时制造两个问题：处理发生在整村层面，而搬迁户往往从原村名册里消失，安置社区与迁出社区不可比。

**干部激励。** 地方官员考核含减贫指标，驻村工作队的评价也看可测量结果。这意味着上报的结果是激励下的均衡产物，不是独立测量；任何声称项目降低了可测贫困的研究都要处理这个问题。

## 时间线

| 年份 | 事件 | 对研究的意义 |
|---|---|---|
| 20 世纪 90 年代末 | 城市居民最低生活保障制度建立 | 地方收入底线，县际差异可作断点 `[待核实]` |
| 2003 | 新型农村合作医疗试点 | 分批推进的服务可及性冲击 `[待核实]` |
| 2006 | 全面取消农业税 | 全国同一日期的农户收入冲击 |
| 2000 年代中期 | 农村低保全国推开 | 资格与补助水平存在县际差异 `[待核实]` |
| 2010 年代 | 承包地确权登记颁证 | 分批确权；结果变量是出租、投资与外出 |
| 2014 | 贫困户建档立卡 | 为定向转移支付提供户级名册 `[待核实]` |
| 2015 | 关于打赢脱贫攻坚战的决定发布 | 划定集中攻坚期及其截止点 `[待核实]` |
| 2016 至 2020 | 易地扶贫搬迁实施 | 整村处理叠加选择性样本流失 |
| 2020 | 贫困登记收官 | 攻坚期结束；回顾性设计的窗口到此为止 |
| 2021 | 转向乡村振兴 | 2020 年后的政策框架不同，不宜外推 |

## 可直接引用的段落

中国农村的贫困治理把全国性目标与地方化执行结合在一起。贫困户由村级程序对照当地适用的标准认定，认定后与指定干部和驻村工作队结对，工作队的考核依据是可测量的结果是否改善。由于资格是地方行政决定而不是全国统一规则，不同县里收入相同的两户人家未必获得相同待遇，县因而成为观察政策最自然的单位。2010 年代中期启动的脱贫攻坚强化了这套体系，并在 2020 年以贫困登记收官 `[待核实]`，这一时点界定了回顾性评估可用的时间窗口。

土地与公共服务提供了另外两条边际。农村土地归集体所有；2010 年代的承包地确权登记把农户承包权登记在图册上并允许出租，因此确权在县与县之间的进度差异，是土地相关结果变量可用的变异来源。合作医疗与义务教育通过分批推进扩展，而不是全国同一天落地；撤点并校则改变了农户到学校的距离。这三类处理的强度都随县与村不同，本文在这一层面上度量处理 `[待填]`。干部考核是另一项制度特征：驻村工作队与县级官员按可测量的减贫成效接受考核，因此上报的结果是在行政激励下生产的，解读时应当把这一点考虑进去。
