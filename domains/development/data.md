# 发展经济学：数据

## 数据来源

发展经济学的数据分三层，论文通常至少要拼接其中两层。住户调查提供结果变量与资格变量；行政记录提供项目参与和地方政策参数；县级或村级统计资料提供协变量和划定对照组所需的地理信息。

全国性住户面板是骨架。中国家庭追踪调查（CFPS）是两年一期的全国面板，含收入、消费、健康、教育与迁移模块，并配套社区问卷，可与家户文件匹配。中国健康与营养调查（CHNS）提供时间跨度更长的分省面板，营养与健康变量细。中国家庭收入调查（CHIP）与中国家庭金融调查（CHFS）常用于收入分布、财富与借贷研究，两者的波次结构、地理覆盖都不同，使用前必须核对。中国综合社会调查（CGSS）是重复截面而不是面板。

行政与项目记录决定处理。县级民政部门保存低保名册与当期标准；扶贫建档立卡记录提供攻坚期的户级与村级名单；省、县的实施通知、工作报告与预算文件标出推进时间和分配规则。学校、卫生室、道路的选址可以从教育、交通年鉴与地图图层重建。

村级调查是田野部分。研究团队自行采集村庄名册、村财务、到县城距离、以及各村获得的项目清单。这类数据很少公开，因此论文要交代工具、村庄抽样与入户日期。复现包应包含问卷、编码簿与匿名化的村级文件；如果做不到，就说明哪些能提供、哪些不能。

## 变量与口径

| 变量（英文原名） | 定义 | 来源 |
|---|---|---|
| household income per capita | 调查报告的年家庭收入除以常住人口 | CFPS、CHIP、CHFS |
| poverty status | 农户收入是否低于当期适用贫困线的指示变量 | 调查收入加当期官方线 |
| dibao receipt | 参考年份是否领取最低生活保障 | 调查模块与县级民政名册 |
| local dibao standard | 县里为参考年份设定的月收入标准 | 县级民政文件 |
| program participation | 村或户是否出现在参考年份的项目名单上 | 县、省项目记录 |
| village treatment status | 村是否被选中，以及属于哪一批 | 实施通知与工作报告 |
| land contract rights | 农户是否持有承包地的登记证书 | 确权记录与调查 |
| land rented out | 参考年份是否把承包地流转给他人经营 | 调查土地模块 |
| migration | 家庭成员是否在外县务工满一个月 | CFPS、CHIP |
| children's schooling | 学龄子女的入学与年级，以及到学校的通行时间 | 调查教育模块与村级问卷 |
| health insurance | 每位成员是否参加新农合或城乡居民医保 | 调查健康模块 |
| distance to county seat | 村庄到县政府驻地的公路距离或通行时间 | 村级问卷与 GIS |
| digital financial inclusion index | 衡量数字金融服务渗透率的县—年指数 | 公开指数，县—年层面 |

## 覆盖范围

| 数据 | 时期 | 层级 | 说明 |
|---|---|---|---|
| CFPS | 2010 基期，两年一期 | 个人与家户 | 社区问卷可与村匹配 `[待核实波次]` |
| CHNS | 长时段分省面板 | 个人与家户 | 营养与健康变量细 `[待核实波次]` |
| CHIP | 多期 | 家户 | 偏重收入；各期省份覆盖需核对 `[待核实]` |
| CHFS | 多期 | 家户 | 财富与金融；抽样框需核对 `[待核实]` |
| CGSS | 年度或双年度截面 | 个人 | 重复截面，不能当面板用 `[待核实]` |
| 县级统计年鉴 | 年度 | 县 | 财政、人口与农业变量 |
| 项目记录 | 与事件相关 | 县、村、户 | 覆盖与变量名因项目而异 |
| 村级田野调查 | 因研究而异 | 村 | 抽样与入户日期必须交代 |

## 已知问题

- 调查收入与行政认定收入是两个不同的构念。回忆期、转移支付的处理、自产自消部分的折算方式都不同，用其中一个构造的门槛不等于另一个的门槛。
- 面板流失不是随机的。迁移与死亡恰好带走受土地与扶贫政策影响最大的农户，因此要分波次、分处理状态报告流失率，并给出界估计。
- 村庄名单会因行政合并而变动。上一期存在的村下一期可能没了，按名称合并不可靠；要按编码匹配，并记录每一次手工合并。
- 项目名单并不完整。小型基础设施项目可能落地而未进县名单，需与村级自报交叉核对。
- 地理标识常常比处理更粗。县代码随边界改革而变，有时只能拿到地级市代码。
- 各调查的权重与抽样框不同。两套调查不加权重调和就合并，得到的水平值没有哪一套调查支持。
- 田野采集本身有需求效应：调查员知道假设，受访者会学到什么样的回答被奖励。设计允许时应让调查员对处理状态保持盲态。
- 田野数据涉及伦理与个人信息保护。要报告知情同意程序、伦理批件、以及家庭标识的存放方式，因为《个人信息保护法》的要求在投稿阶段已常被核查。
