# 行为与实验经济学：数据

## 数据来源

实验数据是采出来的，不是拿来的，因此"数据来源"指的是招募渠道、运行实验的软件，以及支付记录。招募渠道决定了样本，写清楚的程度要达到：另一个团队据此能重复出来——被试库、招募文案、筛选条件，以及平台功能（写平台具备什么功能，不写版本号）。

实验室数据来自高校被试库。被试通过公告、长期名册或课堂招募，实验在机房进行，座位数固定。软件会写出分配文件、决策文件与支付文件，三份文件在分析前必须用被试编号连接起来。

在线数据来自国内研究平台（Credamo 见数及同类平台）与国际平台（Prolific、MTurk）。这些平台提供被试标识、筛选题答案、每页停留时间，有时还有质量标记。平台自带的质量标记不能替代研究内置的注意力检查。

可复现材料来自三处。Open Science Framework 存放预注册、实验说明、刺激材料与分析代码。AEA RCT Registry 存放田野实验的预分析计划。期刊的复现包存放已发表实验的数据与代码，是了解某个范式在实践中如何实现的最快途径。中国的实验数据多为自采，能被他人复用的比例很小；即便数据不能公开，也应当把材料存档。

## 变量与口径

| 变量（英文原名） | 定义 | 来源 |
|---|---|---|
| treatment | 分配给被试的随机化条件 | 分配文件 |
| contribution | 公共品博弈中投入公共账户的筹码或金额 | 决策文件 |
| bid | 拍卖或 BDM 程序中提交的报价 | 决策文件 |
| WTP | 用激励相容机制引出的对某商品的支付意愿，元 | 决策文件 |
| discount rate | 由多价格表或凸时间预算推出的年化贴现率 | 决策文件 |
| risk aversion | Holt-Laubach 或 Binswanger 任务得到的曲率参数 | 决策文件 |
| loss aversion | 混合赌局任务中损失系数与收益系数之比 | 决策文件 |
| effort | 真实努力任务的产出，例如正确完成的滑块数 | 决策文件 |
| CRT score | 认知反思测验的答对题数 | 实验后问卷 |
| attention check | 是否通过预设注意力题目的指示变量 | 问卷与页面停留时间 |
| manipulation check | 被试对目标操纵维度的报告 | 结果变量之后的问卷 |
| participant id | 连接分配、决策、支付与问卷的唯一标识 | 招募文件 |

## 覆盖范围

| 数据 | 年份 | 层级 | 样本量级 |
|---|---|---|---|
| 高校实验室实验 | 持续 | 被试—场次 | 每项研究约百级被试 `[待核实]` |
| 国内在线平台 | 持续 | 被试 | 每项研究约千级被试 `[待核实]` |
| 国际在线平台 | 持续 | 被试 | 每项研究约千级被试 `[待核实]` |
| 结合行政记录的田野实验 | 因项目而异 | 个人或企业 | 约千级至万级单位 `[待核实]` |
| Open Science Framework 存档 | 持续 | 研究 | 不定，多数情况下只有材料 `[待核实]` |
| 期刊复现包 | 持续 | 研究 | 因期刊政策而异 `[待核实]` |

## 已知问题

- 学生样本年轻、受教育程度高、集中在少数高校。报告年龄、性别与专业分布，不要把样本描述成中国人口的代表。
- 在线平台的面板构成随时间变化，同一平台在不同年份可能给出不同样本。记录招募的时间窗与筛选条件，并把样本与平台公布的面板结构作比较。
- 处理跨多轮发放时，流失率会随处理臂不同。报告分臂流失率，并检验流失是否预测结果。
- 翻译本身就是处理的一部分。如果实验说明从英文翻译而来，报告翻译程序，并用预实验检查理解程度，因为翻得不好的框架会改变行为。
- 报酬相对于收入很小。报告支付分布，并在设计允许时改变报酬水平，以证明行为不是由出场费单独驱动的。
- 多结果变量很常见，且很少被完整预注册。把完整问卷与分析脚本存档，让读者能看到测了哪些结果、报了哪些结果。
- 被试数据属于《个人信息保护法》意义上的个人数据。把标识信息与决策数据分开存放，并写明保存期限与可访问人员。
- 会话日志记录的是软件显示了什么，不是被试理解了什么。保留原始页面停留时间与开放题作答，因为它们是理解程度与需求效应的证据。
