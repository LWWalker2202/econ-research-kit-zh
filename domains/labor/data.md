# 劳动经济学：数据来源

中国劳动经济学实证研究用的数据，基本集中在几套微观调查加人口普查。每套数据的设计目的不同，本领域多数审稿问题都出在把数据用到了它不是为此设计的边际上：用住户收入调查算小时工资，用退休调查研究劳动年龄人口的就业，或用重复截面做面板论断。本文件把每个数据源对应到它擅长测量什么、以及它根本不测量什么。

## 数据来源

**中国住户收入调查（China Household Income Project, CHIP）。** 重复截面，包含 1988、1995、2002、2007、2013 和 2018 等年份 [待核实]，城镇、农村与流动人口分别抽样。它的收入分项最细，时间跨度最长，是研究工资结构与收入差距的标准数据源。它不是面板，调查年份间隔也不固定。

**中国家庭追踪调查（China Family Panel Studies, CFPS）。** 自 2010 年起、每两年一轮的追踪调查 [待核实]，覆盖个人、家庭与社区。它设有户籍与迁移模块，以及完整的就业与工资题组，因此可以支撑劳动流动与教育回报的面板设计。工资题在各轮之间有改动，省份—年份单元偏薄。

**中国健康与养老追踪调查（China Health and Retirement Longitudinal Study, CHARLS）。** 自 2011 年起、每两年一轮，样本为 45 岁及以上人群 [待核实]，含较完整的退休、养老金、健康与消费模块，是退休设计以及健康—劳动交互研究的主力数据。它不代表劳动年龄人口，因此用 CHARLS 估出的就业率与工资水平不能当全国劳动力市场统计来读。

**中国综合社会调查（Chinese General Social Survey, CGSS）。** 2008 年以前基本逐年、之后不定期开展 [待核实]。覆盖职业、行业、收入、户籍与态度。它适合做截面工资差距，也适合用来校验职业与行业编码的分布，但没有面板结构，收入变量是较宽的区间口径而非工资。

**中国劳动力动态调查（China Labor-force Dynamics Survey, CLDS）。** 自 2012 年起 [待核实]，以劳动力为主题，含家庭成员名册、工作特征、就业状态与迁移史。它是公开数据中研究非正规就业与工作质量最好的一套，代价是时间跨度短于 CHIP 与 CFPS。

**全国人口普查与 1% 人口抽样调查。** 普查年份及之间的 1% 抽样调查。覆盖全国、近乎全样本，逐人记录职业、行业、教育、户籍与迁移，但没有工资信息。它在劳动研究中的角色是提供分母、迁移流量与再加权目标，而不是提供结果变量。

**城镇住户调查（Urban Household Survey, UHS）。** 国家统计局组织的年度城镇户籍住户调查，收入与支出分项较细。它排除大部分流动人口，只覆盖城镇户籍住户，因此适合研究 2010 年代以前的城镇工资结构，不适合做任何涉及迁移的问题。2013 年之后并入全国住户调查 [待核实]。

## 变量与口径

下表给出多数公开数据说明中的变量名，具体轮次的名称需按当年问卷核对，因为命名习惯逐轮有变动。

| 概念 | 常见变量名 | 需要确认什么 |
| 个人标识 | pid 或 ID | 跨轮次是否稳定 [待核实] |
| 家庭标识 | fid 或 householdID | 家庭构成与收入是否在同一时点测量 |
| 省份 | provcd 或 province | 编码是否跨轮次统一 |
| 户籍 | hukou 或 hukou status | 农业与非农业、本地与非本地是否都可得 |
| 教育 | edu 或最高学历 | 是学历类别还是折算年数 |
| 工资 | wage 或 income | 参考期，以及是否含奖金 |
| 就业 | employ 或工作状态 | 参考周还是参考年 |
| 行业 | industry code | 分类版本与位数 |

| CFPS | 2010 年起，每两年一轮 [待核实] | 个人、家庭、社区 | 约万户级 [待核实] |

## 已知问题

1. 收入存在截顶与整数化。月度收入在整数处堆积，会扭曲上尾分布，使分位数估计不稳定。
2. 收入口径逐轮变化：参考期、是否含奖金与实物收入、是问净收入还是总收入，都发生过改变。合并各轮之前必须逐年比对问卷。
3. 自雇收入与农业收入不是工资，但会进入总收入。把它们混入因变量，会改变估出的教育回报。
4. 户籍与迁移状态都在调查时点测量，二者都是迁移决策的结果。任何把它们当控制变量的设计，都要说明它们为何是前定的。
5. 各轮、各收入分项的回忆期不同，可能造出实际不存在、由调查设计造成的工资变化。
6. 追踪调查存在样本流失与补充样本。流失与迁移、失业相关，而这恰是劳动研究要研究的结果，因此必须报告逆概率权重，并给出界。
7. 1% 人口抽样没有收入变量，职业与行业为自报且较粗。它适合构造分母与再加权目标，不适合估工资方程。
8. 城镇住户调查覆盖城镇户籍住户、排除大部分流动人口。用该数据做迁移研究而不说明这一点，估出的只是已在城市落户者之间的工资差距。
