# 公共经济学：处理变量的构造

这个领域的处理变量几乎不能直接从政策文件上抄下来。转移支付在预算科目里，税收按公式分成，试点身份是地方政府因为某些与研究结果相关的理由才拿到的标签。构造处理变量，就是决定政策哪一个边际携带变异、记录把规则映射成变量的那条规则、并写明在什么假设下这个变异是外生的。下面几张表列出最常见的定义、每种定义换来的假设，以及最容易被审稿人打回的错法。

## 处理变量怎么构造

| 处理变量定义 | 数据来源 | 隐含假设 | 什么时候用 |
|---|---|---|---|
| 人均转移支付冲击：两个预算年度之间按公式分配的一般性转移支付人均变化额 | 财政部转移支付通知、省级决算 | 公式及其带入的地方特征没有对结果变量作出反应 | 研究财政资源增加对地方公共品供给的影响 |
| 财政支出强度：地方财政支出占本地 GDP 的比重，或某类支出占总支出比重 | 《中国财政年鉴》、县域与城市统计年鉴 | 强度差异反映政策选择，而非需求驱动的支出 | 公共品供给的横截面研究，变异是持续的而非某次改革 |
| 税收分成率：某一税种地方留存比例，或地方收入占本地创造收入的比重 | 省级财政统计与分成规则文件 | 分成规则由上级设定，不与本地结果变量共同决定 | 研究收入激励如何塑造地方行为，尤其围绕 1994 年改革 |
| 试点身份：县或企业被列入某项改革的试点虚拟变量，按官方启动日期赋 1 | 改革通知、省级实施方案 | 进入试点不由结果变量趋势驱动；或选择倾向可以建模 | 围绕有明确文件的事件研究与交错双重差分设计 |
| 政策强度打分：由文件数量、发文层级、要求严格程度合成的指数 | 收集的改革文件与实施细则 | 打分按"对同一政策的暴露程度"排序，且结果变量不影响打分 | 同一政策由多份文件落地、没有单一突破时点时 |

| 结果变量 | 需要写明的定义 | 定义选择会怎样改变估计 |
|---|---|---|
| 地方公共支出 | 按功能分类的预算内支出，人均、实际值 | 是否包含资本性支出，在某些情境下会改变符号 |
| 转移支付依赖度 | 收到的转移支付除以地方总收入或总支出 | 用支出做分母会引入与结果变量的机械相关 |
| 地方债务 | 年末有息债务余额，能拿到时包含融资平台债务 | 预算内与预算外口径给出不同水平，也给出不同趋势 |
| 企业税负 | 缴纳税费除以销售收入或增加值 | 销售分母对企业规模与转让定价敏感 [待核实] |
| 政策采纳日期 | 该地首次出现在改革文件中的年份 | 按公布日而非实施日赋值会让处理时点整体前移 |
| 分行业改革暴露度 | 改革点名行业内本地就业或产出占比 | 暴露份额可能对改革前增长内生 [待核实] |

## 各定义的识别假设

| 定义 | 必须成立什么 | 什么会推翻它 |
|---|---|---|
| 人均转移支付冲击 | 公式变化不是对结果变量的回应，且没有别的财政变化同期发生 | 同期税制调整，或一场针对同一笔钱的扶贫运动 |
| 财政支出强度 | 强度变异不由同期本地需求驱动 | 反向因果：需求冲击同时抬高支出与结果 |
| 税收分成率 | 规则制定时未预判本地结果 | 某项改革明确以该结果为目标 |
| 试点身份 | 不存在选择性入选，或选择只基于可观测特征且可以建模 | 上级专挑事前趋势最强的地区 |
| 政策强度打分 | 打分度量的是对同一政策的暴露，不是结果本身 | 文件是对本地问题作出的回应，而结果也反映这些问题 |
| 分行业改革暴露度 | 改革前的行业结构本身不是结果变量的函数 | 改革前已出现预期性调整 |

## 常见构造错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 把所有转移支付当成一个桶 | 混淆一般性与专项资金，两者分配规则不同 | 按渠道拆分转移支付变量，分别报告 |
| 用政策公布年份作为处理年份 | 实施存在时滞时，估计被稀释 | 同时报告公布日与生效日，两种设定都跑 |
| 除以本地 GDP 这类内生分母 | 处理变量与结果变量出现机械相关 | 改用实际人均水平，或用基准期固定的分母 |
| 忽视同一窗口内叠加的其他改革 | 系数同时吸收了多项政策 | 把窗口内所有在行政策列出，并证明主结果在控制或剔除后仍成立 |
| 按文件数量给政策强度打分 | 对文书数量而非政策力度敏感 | 按发文层级加权，并按文件是否改变规则来加权 |
