# 国际贸易与空间经济学：数据

## 数据来源

**中国海关数据库（China Customs Trade Database）。** 按企业、产品、贸易方式与伙伴国记录进出口逐笔交易，含数量与美元金额。这是贸易暴露研究的主力微观数据：它同时给出企业、HS 编码、贸易方式（加工贸易与一般贸易）、关区、以及目的地或原产国。多数论文样本覆盖 2000 年至 2016 年[待核实]，之后年份不完整，因此企业层面贸易设计的样本窗口必须明确写出。企业标识是海注册编码，与工业企业数据库的代码不同。

**中国工业企业数据库（Chinese Industrial Enterprises Database, CIED）。** 规模以上制造业企业年度数据，口径见工业企业数据库的数据字典条目。这里用它把企业特征接到海关交易记录上，并把企业映射到二位码行业，从而把产品层面的冲击加总到企业或地区。海关记录与工业企业记录的匹配依赖企业名称、地址、电话与邮编，仍有相当比例的记录匹配不上。

**城市与县域统计。** 《中国城市统计年鉴》与《中国县域统计年鉴》报告地级市与县的生产总值、分行业就业、工业产出、外商直接投资与人口，通常同时给出全市与市辖区两种口径。它们是本地结果变量以及暴露度量所需期初行业结构的标准来源。

**夜间灯光。** DMSP-OLS 与 NPP-VIIRS 的网格辐亮度，在统计缺失或不可靠处作为本地经济活动的代理。两种传感器的重叠期很短，饱和与定标特性也不同。

**产品层面双边贸易。** CEPII-BACI 与 UN Comtrade 提供 HS6 层面按年双边流量，用于构造世界需求冲击、来自第三国的进口渗透以及伙伴国层面的暴露。镜像统计系统性不一致：进口国与出口国报告的价值不同，货物经转口地过境也会造成差异。

**关税税则与贸易政策工具。** 《中华人民共和国进出口税则》按 HS 行给出法定最惠国税率；TRAINS 与 WTO 关税数据库可用于交叉核对；加工贸易的禁止类、限制类目录界定哪些产品不能免税加工。

**交通网络与时刻表。** 铁路时刻表给出城市对旅行时间与直达车次；铁路与公路统计公报给出开通年份与里程；港口统计给出吞吐量。时刻表快照很重要，因为运行图会定期调整，单一年份的旅行时间只是对一个变化对象的点估计。

**行政区划。** 民政部行政区划代码与年度行政区划调整公告记录县何时改为区、县级市何时升格、代码何时重编。跨越这些公告的城市面板需要代码沿革，而不只是当前代码。

## 变量与口径

| 变量 | 字段或构造方式 | 需要检查什么 |
|---|---|---|
| 企业标识 | 企业代码（海关注册编码） | 跨年是否稳定；与工业企业数据库如何匹配 |
| 企业所在地 | 注册地的行政区划代码 | 代码是地级市、县，还是市辖区 |
| 产品 | 记录位数上的 HS 编码 | 比较的两个年份是否使用同一版 HS 分类 |
| 贸易方式 | 贸易方式（一般贸易、进料加工、来料加工） | 暴露度量是否包含加工贸易 |
| 金额与数量 | 美元金额、数量、计量单位 | 记录间计量单位是否变化；金额未扣除再出口 |
| 目的地或原产国 | 伙伴国代码 | 经香港转口的贸易算给最终目的地还是转口地 |
| 关税 | HS 行的法定最惠国税率，按期初贸易加权的平均 | 权重取期初贸易还是当期贸易 |
| 地区行业份额 | 工业企业数据库的二位码行业就业或产出份额 | 行业分类在历次修订间是否一致 |
| 旅行时间 | 时刻表给出的城市对网络旅行时间 | 站到站还是门到门；取哪一年的运行图 |
| 灯光 | 网格单元上的校准辐亮度 | 两种传感器的序列是否做过协调 |
| 市场可达性 | 收入加权、以旅行成本倒数为权重的市场潜力 | 目的地的收入是否滞后到冲击之前 |

## 覆盖范围

| 数据 | 年份 | 层级 | 样本量级 |
|---|---|---|---|
| 中国海关数据库 | 2000 年至 2016 年[待核实] | 企业—产品—伙伴国 | 每年约十万至百万家企业[待核实] |
| 中国工业企业数据库 | 1998 年至 2013 年，中间有缺年 | 企业 | 每年约十万家企业[待核实] |
| 城市统计年鉴 | 1990 年代起按年 | 地级市 | 数百个城市 |
| 县域统计年鉴 | 按年 | 县与区 | 约两千个县级单位[待核实] |
| DMSP-OLS 夜间灯光 | 1992 年至 2013 年 | 网格单元 | 全球覆盖 |
| NPP-VIIRS 夜间灯光 | 2012 年起 | 网格单元 | 全球覆盖 |
| CEPII-BACI 与 UN Comtrade | 1995 年起[待核实] | 出口国—进口国—HS6 | 所有报告国 |

## 已知问题

1. 海关企业编码并非永久不变：企业重新注册或改变贸易安排后可能换用新编码，因此不平衡的企业面板会因行政原因而非经济原因流失和新增样本[待核实]。
2. HS 分类经过多次修订，不套用对应表的产品层面面板会在每次修订处断裂；部分单元格是多对多映射，映射后的度量带有误差，应当报告。
3. 加工进口免征关税，因此用全部海关进口构造的关税暴露会低估加工企业的暴露，并高估平均的关税下调反应。
4. 海关金额是边境总值而非增加值；经香港等转口地的再出口在部分序列中记给转口地、在另一些序列中记给最终目的地，双边总量因此不同。
5. 工业企业数据库在若干关键财务项上存在缺年与口径断点，企业层面的财务变量匹配应限制在可比年份之间。
6. 城市统计同时报告全市与市辖区两套口径；未加选择地拼接会混入两个总体，二者在吸纳了县的城市差异最大，合并带来的人口与产出跳升容易被误读为政策效应[待核实]。
7. 夜间灯光在中心城区饱和、在边界处溢出，且 DMSP 与 VIIRS 两个时代之间传感器更换，未经交叉定标前水平值不可跨期比较。
8. 基于时刻表的旅行时间会随铁路运行图调整而变动，因此旅行时间冲击中包含与基础设施投资无关的调度变化。
