# 中国健康与养老追踪调查（CHARLS）

## 基本信息

| 项目 | 内容 |
|---|---|
| 全称（中文） | 中国健康与养老追踪调查 |
| 全称（英文） | China Health and Retirement Longitudinal Study |
| 简称 | CHARLS |
| 维护机构 | 北京大学国家发展研究院（National School of Development, NSD）主持，北京大学中国社会科学调查中心（ISSS）执行 |
| 起始年份 | 2011 年全国基线调查；2008 年曾在两省做过预调查 |
| 更新频率 | 每两到三年一轮 |
| 观测层级 | 个人、家庭、社区三级 |

## 变量表

| 变量名 | 中文名 | 含义与口径 | 典型取值 |
|---|---|---|---|
| `ID` | 个人标识 | 个人层面的永久编号，是跨年追踪同一个人的主键 | 唯一字母数字编码，跨轮稳定 |
| `householdID` | 家庭标识 | 家庭编号，把成员挂到同一轮的家庭记录上 | 唯一编码，随轮次变化 |
| `communityID` | 社区标识 | 村居编号，是初级抽样单位 | 唯一编码 |
| `wave` | 调查轮次 | 调查轮次，通常以调查年份存储 | 2011、2013、2015、2018、2020 |
| `province` | 省份 | 居住地所在省份 | GB/T 2260 省份代码 [待核实] |
| `urban_nbs` | 城乡标识 | 按国家统计局城乡划分得到的城乡属性 | 1 为城镇、0 为乡村 [待核实] |
| `gender` | 性别 | 受访者性别 | 男或女，多数轮次编码为 1/2 [待核实] |
| `birthyear` | 出生年 | 出生年份，用于计算年龄和界定 45 岁及以上样本 | 四位数年份 |
| `education` | 受教育程度 | 已完成的最高教育层级 | 分类变量，约 1 至 11，随轮次略有差异 [待核实] |
| `hukou` | 户口类型 | 农业户口与非农业户口（后期出现居民户口） | 分类变量 [待核实] |
| `adl` | 日常生活活动能力 | 日常生活活动能力受限的项数 | 计数，一般为 0 至 6 [待核实] |
| `cesd` | 抑郁量表得分 | 由心理健康模块构造的 CES-D 10 得分 | 序次得分，取值范围以当年 codebook 为准 [待核实] |

上表使用的是随数据发布的整合文件命名。各模块原始文件用的是问卷题号，健康、认知和生物标记物变量最容易出现跨轮换名，构造前必须对照当年 codebook。

## 已知问题

- 年龄口径有限制。样本以 45 岁及以上居民为目标人群（配偶不受年龄限制）[待核实]，不能代表全体成年人。教育回报、职业早期等议题的结果无法外推到全人群。
- 流失与死亡要分开处理。高龄和健康状况差的样本流失率最高；死亡记录在单独的退出（exit）文件里，把死亡当作流失会系统性低估健康与收入结果，建面板前必须先合并退出文件。
- 生物标记物只是子样本且不是每轮都有。血液样本、体测和血压并非全员采集，血液模块的应答率低于主问卷，会重新引入选择性问题。
- 存在代答。无法作答的受访者由他人代答，代答比例随年龄上升，且与所研究的健康状况本身相关。
- 问卷结构中途调整过。2018 年轮次对多个模块做了重构并引入新的量表，变量名和分类编码跨轮变化，跨年变量要逐条目核对。
- 收入与消费按家庭采集。做个人层面分析需要给出分配规则，常用人均或等价规模折算。
- 地理标识的可得性分级。省份和县区对外发布，村居标识需另行申请 [待核实]。另外，2008 年预调查只覆盖两个省，不能与全国基线合并使用。
- 自报健康存在测量误差。未就诊、未确诊的慢性病会被漏报，用自报患病率或就医次数做被解释变量会低估真实效应并造成衰减偏误。

## 获取方式

| 项目 | 内容 |
|---|---|
| 申请入口类型 | 学术用途在线申请，免费 |
| 申请渠道 | 北京大学国家发展研究院（NSD）CHARLS 项目组，经由北京大学中国社会科学调查中心（ISSS）的数据平台 |
| 是否需机构账号 | 需注册；使用机构邮箱申请处理更快 [待核实] |
| 费用 | 学术用途免费 |
| 伦理审查 | 调查本身已通过伦理审查；使用者所在机构是否另行要求，由其自行判断 |
| 使用协议 | 不得向第三方再分发、不得商业使用；发表须引用数据来源并致谢调查项目；部分模块需单独申请并另签协议 |
