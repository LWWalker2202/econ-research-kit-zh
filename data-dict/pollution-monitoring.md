# 中国污染监测数据（国控站点与重点排污单位在线监测）

## 基本信息

| 项目 | 内容 |
|---|---|
| 全称（中文） | 中国污染监测数据（国控站点与重点排污单位在线监测） |
| 全称（英文） | Pollution monitoring data in China: national control air-quality stations and online monitoring of key pollutant discharging units |
| 简称 | 无通用简称 [待核实] |
| 维护机构 | 生态环境部（Ministry of Ecology and Environment, MEE）；全国环境空气质量监测网由中国环境监测总站（China National Environmental Monitoring Centre, CNEMC）运行 |
| 起始年份 | 空气质量新标准数据自 2013 年首批城市实时发布，2015 年覆盖全部地级及以上城市 |
| 更新频率 | 空气质量为小时和日尺度；在线排放监测为日或月尺度 |
| 观测层级 | 站点—小时、站点—日、城市—日、企业排放口—日 |

## 变量表

| 变量名 | 中文名 | 含义与口径 | 典型取值 |
|---|---|---|---|
| `station_id` | 站点编码 | 国控监测站点的编号 | 唯一编码；站点迁址时须核对编码是否延续 |
| `city_code` | 城市代码 | 站点所属城市的行政区划代码 | GB/T 2260 数字代码 |
| `date` | 日期 | 观测所属日历日期 | 年—月—日 |
| `hour` | 小时 | 观测所属小时，按当地时间 | 0 至 23 |
| `pm25` | PM2.5 浓度 | 细颗粒物浓度 | 微克每立方米 |
| `pm10` | PM10 浓度 | 可吸入颗粒物浓度 | 微克每立方米 |
| `so2` | 二氧化硫浓度 | 二氧化硫浓度 | 微克每立方米 |
| `no2` | 二氧化氮浓度 | 二氧化氮浓度 | 微克每立方米 |
| `o3` | 臭氧浓度 | 臭氧浓度 | 微克每立方米 |
| `aqi` | 空气质量指数 | 由各污染物分指数合成的空气质量指数 | 整数，按固定分级表计算 |
| `primary_pollutant` | 首要污染物 | 当日分指数最高的污染物 | 污染物名称或代码 |
| `enterprise_name` | 企业名称 | 在线监测数据中重点排污单位的名称 | 文本，需与当年重点排污单位名录匹配 |
| `pollutant` | 污染物 | 排放口所监测的污染物 | 编码化的污染物名称 |
| `concentration` | 排放浓度 | 排放口实测浓度 | 毫克每立方米或毫克每升，随污染物而定 |
| `flow` | 流量 | 排放口的废气或废水流量 | 单位时间体积 |

站点级空气质量文件与企业级在线监测文件是两套产品，由同一系统的不同部门维护，不能当成一个数据集使用。

## 已知问题

- 站点面板不连续。国控站点有新增、迁址和撤销，一个在各年都出现的站点编码，其物理位置或监测方法也可能变过。建面板要以固定站点清单为准，并报告有多少站点退出。
- 2013 年前没有全国口径的 PM2.5。新标准只在首批城市先行实施，2015 年才覆盖全部地级及以上城市；把 2013 年当作全国的 PM2.5 前期会严重误判政策效果。
- 缺测有时被记成 0。日均值要求有效小时数达到门槛，把未上报的小时按 0 处理会把城市均值系统性压低，容易被误读成治理成效。
- 实时发布值与年鉴审定值不一致。官方年报用的审定数据与平台实时值会有差异，混用前必须确认序列来源，而版本修订并不逐条留痕。
- 站点选址不是随机的。国控站点多位于城市建成区，不能代表县域和农村暴露水平；县级设计要么另找数据源，要么明确建立暴露模型。
- 在线排放数据由企业自报。数据经平台由企业填报，覆盖范围跟随逐年调整的重点排污单位名录，被监测集合本身是内生的选择。
- 排放口与企业不是一一对应。排放按排放口上报，一家企业可能有多个排放口，汇总到企业层面需要做匹配，匹配率要报告。
- 只监测规定的污染物。无组织排放和许可或监测要求之外的污染物不进入数据，因此在某个被监测污染物上得到零效应，不能排除向未被监测污染物的替代。

## 获取方式

| 项目 | 内容 |
|---|---|
| 申请入口类型 | 站点级空气质量可公开下载；长历史序列与企业级在线监测需申请或购买 |
| 申请渠道 | 空气质量走中国环境监测总站（CNEMC）及省市级环境监测机构；在线监测走生态环境部（MEE）及省级生态环境部门 |
| 是否需机构账号 | 公开实时查询页面不需要；批量下载与历史数据需要 [待核实] |
| 费用 | 非商业用途免费；部分历史产品与企业级产品收费 |
| 伦理审查 | 不涉及人体被试伦理审查，但企业标识与排污许可信息可能属保密范围 |
| 使用协议 | 不得再分发，使用时注明监测机构；商业用途须另行取得许可；以提供数据的平台条款为准 |
