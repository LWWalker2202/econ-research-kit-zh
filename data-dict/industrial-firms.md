# 中国工业企业数据库（CIED）

## 基本信息

| 项目 | 内容 |
|---|---|
| 全称（中文） | 中国工业企业数据库 |
| 全称（英文） | Chinese Industrial Enterprises Database |
| 简称 | CIED |
| 维护机构 | 由国家统计局（National Bureau of Statistics of China, NBS）规模以上工业企业年度调查汇编而成 |
| 起始年份 | 1998 年 |
| 更新频率 | 年度；学界广泛流通的微观数据为 1998 至 2013 年 |
| 观测层级 | 企业（法人）层面 |

## 变量表

| 变量名 | 中文名 | 含义与口径 | 典型取值 |
|---|---|---|---|
| `id` | 企业法人代码 | 企业法人代码，是跨年匹配同一家企业的标识 | 字母数字编码，跨年不稳定 |
| `year` | 年份 | 记录所属的统计年度 | 常用文件为 1998 至 2013 年 |
| `province` | 省地县代码 | 企业所在的省、地、县行政区划代码，原始文件为合成字段 | GB/T 2260 数字代码，需拆成省、市、县三段 |
| `industry` | 行业代码 | 主营产品所属的四位数行业代码 | GB/T 4754 代码；断点前后版本不同 [待核实] |
| `ownership` | 登记注册类型 | 登记注册类型，用于区分国有、私营、外资等 | 分类代码 |
| `employees` | 从业人员数 | 年末从业人员总数 | 计数，单位为人 |
| `total_assets` | 资产总计 | 年末资产总计 | 元，名义值 |
| `fixed_assets` | 固定资产净值 | 固定资产净值 | 元，名义值 |
| `output` | 工业总产值 | 工业总产值 | 元，名义值 |
| `revenue` | 主营业务收入 | 主营业务收入，也是规模以上门槛的判定依据 | 元，名义值 |
| `export` | 出口交货值 | 出口交货值 | 元，名义值；部分年份缺失 |

原始文件表头为中文。上表的英文变量名是清洗后版本里较通用的叫法，使用时必须对照手上那一版的数据字典，不能默认逐列一一对应。

## 已知问题

- 2011 年规模以上门槛提高。年主营业务收入门槛由 2010 年及以前的 500 万元提高到 2011 年起的 2000 万元，样本因此不是连续面板，观察到的企业进入退出中有一部分是口径变化造成的，不是真实的企业动态。
- 行业代码口径变更。企业行业代码在断点前按 GB/T 4754 的 2002 版、之后按 2011 版划分 [待核实]，前后四位数行业不可直接比较，跨期比较必须经转换表重新归并。
- 2004 年数据有结构性缺口。该年为经济普查年份，工业总产值、工业增加值等关键项缺失或口径不同 [待核实]，不宜当作普通年份直接使用，逐变量核对后再决定是否保留。
- 部分年份缺关键财务项。工业增加值在后期不再填报，出口交货值也有若干年缺失 [待核实]，因此全要素生产率和出口指标无法每年都算得出来。
- 企业代码跨年不稳定。法人代码会变更，跨年匹配通常要靠企业名称、地址、电话等字段组合，匹配率做不到百分之百，论文里要报告匹配率和匹配规则。
- 重复与错报记录常见。同一企业一年内可能出现多条记录，部分数值以千元而非元填报，极端离群值大量存在。必须按明确的规则去重、缩尾，并在复现包里写清规则。
- 数据止于 2013 年。2013 年之后没有可比口径的微观数据发布，需要后期被解释变量的设计必须另找数据源，不能靠该库外推。
- 企业状态需要筛选。文件中混有筹建、停产、破产等状态的企业，计算任何财务比率前都应先按状态字段剔除，剔除规则要报告。

## 获取方式

| 项目 | 内容 |
|---|---|
| 申请入口类型 | 不公开，需机构账号或付费获取 |
| 申请渠道 | 国家统计局（NBS）、高校图书馆，以及对外分发清洗版的科研机构 |
| 是否需机构账号 | 需要；通常走机构许可或数据共享协议 |
| 费用 | 商业数据商按订阅或按次收费；部分高校的机构许可覆盖学术用途 |
| 伦理审查 | 企业层面行政数据不涉及人体被试伦理审查，但企业标识属保密信息，须按协议管理 |
| 使用协议 | 不得转售或再分发；发表须注明数据来源与所用清洗版本，并在复现包中交代清洗规则 |
