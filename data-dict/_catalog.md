# 外部数据目录

## 这个文件是什么

`data-dict/` 分两层。带编号的条目（`cfps.md`、`charls.md`、`industrial-firms.md`、`pollution-monitoring.md`）是档案，每个数据源一篇，按本目录规定的四节写。这个文件是第二层：指向一个外部目录，用来回答更早的那个问题——“我想研究的这个东西，到底有没有对应的数据源，去哪里拿？”

外部目录是 **Econ Datalab（经济学研究数据目录）**，由胡志韧（Zhiren Hu）与童宣奇（Xuanqi Tong）维护，是一份面向实证研究的数据田野指南。此处快照包含 1333 个数据源，覆盖 7 个地区、16 个话题，附 7735 篇应用文献。静态站点，无追踪。

- 在线站点：<https://econ-data.github.io/>
- 源仓库：<https://github.com/econ-data>

编号规则是「地区.类型.序号」：`1.6.1` 表示地区 1（中国）、类型 6（环境）、序号 1（空气污染）。

## 两层是什么关系

两者不是替代关系，也没有哪一层更“正统”。

| 层 | 回答什么问题 | 密度 |
|---|---|---|
| 本目录的编号条目 | 这个数据源里面长什么样，人们通常怎么用错 | 四节齐全：变量名、口径漂移、合并键、获取渠道 |
| Econ Datalab | 有哪些数据源可用，在哪里获取 | 每个源一段概述、获取链接、应用文献 |

规则是：先去外部目录找到源；如果你要跨项目反复用它，就在本目录写一篇编号条目，两层都留着。目录告诉你“这个源存在”；只有条目能告诉后来的人“它 2016 年之后收入变量的定义变了”。

## 怎么查

在仓库根目录下：

```bash
python scripts/lookup_source.py CFPS
python scripts/lookup_source.py --region 中国数据 --topic 环境数据
python scripts/lookup_source.py --id 1.6.1
python scripts/lookup_source.py --list-topics
```

脚本会把目录缓存在用户缓存目录下，超过一周自动重新下载；`--refresh` 强制刷新。没有网络时它会明说，并让你直接去看站点，而不是安静地返回空结果。

## 本目录还缺什么

快照里的 67 个中国数据源，只有四个在本目录有档案。其余是候选，不是缺口：一个数据源值得建条目，是因为有人真用过、并在它身上花了时间。要建就照 `README.md` 里的流程走，外部目录那一条不用动。
