# 中国家庭追踪调查（CFPS）

## 基本信息

| 项目 | 内容 |
|---|---|
| 全称（中文） | 中国家庭追踪调查 |
| 全称（英文） | China Family Panel Studies |
| 简称 | CFPS |
| 维护机构 | 北京大学中国社会科学调查中心（Institute of Social Science Survey, ISSS） |
| 起始年份 | 2010 年基线调查 |
| 更新频率 | 每两年一轮追踪 |
| 观测层级 | 个人、家庭、社区三级 |

## 变量表

| 变量名 | 中文名 | 含义与口径 | 典型取值 |
|---|---|---|---|
| `pid` | 个人标识 | 个人层面的永久编号，是跨年追踪同一个人的主键 | 唯一数字编码，跨轮稳定 |
| `fid` | 家庭标识 | 家庭编号，同一轮调查中每个家庭一条记录 | 唯一数字编码，随轮次变化 |
| `cid` | 社区标识 | 社区或村居编号，是县区以下的抽样单位 | 唯一数字编码 |
| `wave` | 调查轮次 | 调查轮次，通常直接以调查年份存储 | 2010、2012、2014、2016、2018、2020、2022 |
| `provcd` | 省份代码 | 家庭所在省份 | GB/T 2260 代码；两位数或六位数随文件不同 [待核实] |
| `urban` | 城乡标识 | 社区按国家统计局城乡划分得到的城乡属性 | 1 为城镇、0 为乡村（以当年 codebook 为准） |
| `cfps_gender` | 性别 | 受访者性别；部分年份文件里同一概念记为 `gender` | 男或女 |
| `age` | 年龄 | 调查当年的年龄，也可由出生年重新推算 | 整数年 |
| `eduy` | 受教育年限 | 由教育模块构造的已受教育年数 | 整数年，大致 0 至 22 [待核实] |
| `fincome` | 家庭收入 | 调查当年的家庭收入，口径分总收入与净收入两种 | 连续值，单位为元；建议用省级 CPI 平减 |

上表使用的是跨年整合文件的通用命名。各轮原始问卷文件里还存在以题号命名的变量，同名概念在不同轮次也可能换名，使用时必须对照当年 codebook，不能只凭变量名跨轮合并。

## 已知问题

- 追踪流失不是随机的。搬迁家庭、高龄受访者和部分城镇家庭的流失率明显更高，非平衡面板并非随机缺失。论文里要报告各轮应答率 [待填]，并给出加权或平衡子样本下的稳健性结果。
- 家庭编号随轮次变化，且家庭结构会因分家、并户、死亡和新成员加入而改变。直接用 `fid` 当面板编号而不接亲属关系文件，会把新分出的家庭错记到原来的家庭。
- 同一概念在不同轮次可能换名或重新编码，跨年变量必须逐轮构造，不能按变量名直接合并；教育年限和收入是最容易出错的变量。
- 部分模块只在个别轮次调查，例如较细致的心理健康和主观福利量表，这类被解释变量做不了平衡面板。
- 收入与消费在家庭层面采集，且各轮的分项口径不同。做个人层面分析需要给出明确的分配规则，例如人均化或等价规模折算。
- 基线之后样本设计有过调整，后期轮次补加过样本 [待核实]。单轮的权重不能直接套到多轮合并样本上。
- 公开版的地理信息有限：省份可用，部分轮次的县区和村居标识需要另外申请 [待核实]。需要县级处理变量的设计必须单独走一次申请。

## 获取方式

| 项目 | 内容 |
|---|---|
| 申请入口类型 | 学术用途申请，免费 |
| 申请渠道 | 北京大学中国社会科学调查中心（ISSS）的数据平台 |
| 是否需机构账号 | 不需要，但需注册并说明研究用途 [待核实] |
| 费用 | 学术用途免费 |
| 伦理审查 | 调查本身已通过伦理审查；使用者所在机构是否另行要求，由其自行判断 |
| 使用协议 | 不得向第三方再分发、不得用于商业目的；发表时须引用数据来源并致谢调查项目 |
