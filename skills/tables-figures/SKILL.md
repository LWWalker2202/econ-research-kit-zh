# 表与图

## 什么时候进这里

- 初稿的回归表还是 Stata 结果窗口的截图，而目标期刊要求可编辑的表体。
- 审稿意见指出表里查不到标准误、星号没有说明，或者观测数与正文对不上。
- 要把工作论文的手工表全部换成脚本生成，为投稿和复现包做准备。
- 需要一张带置信区间、并把基期明确落在零线上的事件研究系数图。
- 要整理附录，让稳健性检验的列结构与基准回归表逐列对应。

## 输入

| 需要什么 | 从哪来 | 缺了怎么办 |
|---|---|---|
| 冻结的估计结果 | `estimation` 产出的 `output/estimates/` 下文件 | 重跑估计；绝不从日志里手抄数字 |
| 表图与正文论点的对应表 | 论文提纲或初稿的段落安排 | 先写：一张表图一行，写清它支撑哪句话 |
| 变量标签与单位 | `data-prep` 的码本 `codebook/varlabels.csv` | 改标签文件，不改画表脚本；没标签就先用原始变量名 |
| 期刊的表图规范 | 期刊投稿须知 | 先用本 skill 的默认规范，差异处标 `[待填]` |
| 工具链 | Stata 侧的 `esttab` 与 `coefplot`，或 Python 侧的 `pyfixest` 与 `modelsummary` 风格导出 | 一张表图只走一条工具链，并在表注里写明 |

## 步骤

中文期刊的目标形态以 `overrides/journal-cn.md` 为准：那里按 28 篇《经济学（季刊）》与《数量经济技术经济研究》论文实测记录了表题位置、表注写法与图题方向，只有一篇见到的做法标了 `[待核实]`。三条最常写错的：表题在表上方，编号与标题间空一格，标题不以句号结尾；表体不画竖线，横线只用于顶线、表头线与底线；图题在图下方，本 skill 英文默认把图题放在图上方，投中文刊必须反过来。定形前先查该文件里目标刊的做法，再动脚本。

1. 写 `output/tables/table_index.csv`，一行一张编号表图：编号、支撑的正文句子、读取的估计文件、构建状态。完成条件：初稿里出现的每一张表图都有行，且没有一行缺估计文件。
2. 一张表图一个脚本，放在 `code/tables/` 与 `code/figures/` 下；脚本只读冻结的估计文件，不重跑回归。完成条件：改动估计文件里的一个系数，只有对应的表变，其余都不动。
3. 一次性定死数字格式：系数与标准误各三位小数，星号阈值写成 1%、5%、10% 并复制进表注，样本定义写进共享头文件。完成条件：读者只看表注就能还原 p 值区间。
4. 两条工具链输出同一列序。Stata 侧先用 `estimates store` 存住各列设定，再用 `esttab` 导出表体，用 `b()` 与 `se()` 让标准误落在系数下一行，用 `coefplot` 从同一批 stored estimates 出图；Python 侧把 `pyfixest` 的模型对象交给 `modelsummary` 风格的导出器或 `etable`，列序与星号阈值保持一致。完成条件：同一个估计文件下，两条链导出的表逐位相同。可直接照抄的参考实现在 `templates/panel_ols.py` 与 `templates/make_table.do`，钉住的标准输出在 `expected/table1.tex`：跑 `python templates/panel_ols.py --lang zh`，与金样逐行比对，再改脚本。
5. 多列回归表的每一列都补齐四组汇报行：固定效应、控制变量、观测数、拟合优度。完成条件：没有一列把控制变量的取舍藏在表注里。
6. 表注写在表下方并做到自足：被解释变量及其单位、估计方法、样本与样本期、固定效应、聚类标准误的层级、星号说明、资料来源。完成条件：不看正文也能读懂这张表。
7. 出图：点估计加置信区间，基期画在零线上但不估计，坐标轴写明估计量的单位。完成条件：图题措辞与坐标轴标签一致，表图在正文里都被编号引用过。
8. 编译一次做宽度与引用检查：表图不出版心，表题在上、表注在下、图题在下，正文按编号引用每一张表图。完成条件：生成的 PDF 里没有溢出，引用检查没有孤立的表图。

手工表迟早会和正文对不上，而这个矛盾通常在返修阶段才被发现；写脚本的成本只付一次。

## 验收

- [ ] 初稿里每一张编号表图都在 `output/tables/` 或 `output/figures/` 下有文件，并在 `table_index.csv` 里有行。
- [ ] 清空 `output/` 后一条命令重建，全部表图复现，无需手工修改。
- [ ] 系数在上、标准误在下，没有一张表把标准误放到最右一列。
- [ ] 每张表的表注在表下方，写明星号阈值、估计方法、样本、固定效应与聚类层级。
- [ ] 排版后的 PDF 里没有表图超出版心。
- [ ] 每张表图都在正文里被编号引用过，没有指向不存在表图的引用。
- [ ] 同一估计文件下，Stata 与 Python 两条链导出的表逐位相同。

## 常见失败模式

| 模式 | 表现 | 纠正 |
|---|---|---|
| 从结果窗口手抄数字进表 | 模型一改，表不动 | 只读冻结的估计文件，手不打数 |
| 星号说明塞进图题或表题 | 审稿人问一个星号代表几个百分点 | 阈值写进表下方的注 |
| 标准误单放最右一列 | 读者要在页面上来回对齐行 | 标准误放在对应系数的下一行括号里 |
| 表宽超过版心 | 最右一列在 PDF 里被裁掉 | 减汇报行、减小数位，或拆成分栏表 |
| 直接用截图当图 | 印刷尺寸下发虚且不可编辑 | 从绘图脚本导出矢量 PDF，另存一份位图自校 |

## 与其它 skill 的接口

- 上游：`estimation` 交来冻结的估计结果与设定表；`data-prep` 交来变量标签与单位。
- 下游：`report` 消费生成的 `.tex` 与 `.pdf`；`writing` 消费表注与表图—论点对应表；`review` 在回复审稿时引用表图编号。
