# 写作与投稿

## 什么时候进这里

- 估计结果已经定稿，但稿子还像带参考文献的实验记录。
- 摘要要压到刊物规定的字数，又不能把主结果压掉。
- 投稿系统要求关键词、中图分类号、数据可得性声明、基金项目与利益冲突声明。
- 引言必须在第三句给出本文的贡献，而不是拖到第三页。
- 正在写逐条回复，回复里的说法必须与改后的正文对得上。

## 输入

| 需要什么 | 从哪来 | 缺了怎么办 |
|---|---|---|
| 带量级与单位的最终估计 | `estimation` 的产出与已生成的表 | 主结果没定就不写摘要 |
| 表图与论点的对应表 | `output/tables/table_index.csv` | 先建；摘要里每个论断都要落到一张表图上 |
| 目标刊物的体例说明 | 期刊投稿须知 | 先用本 skill 的默认体例，差异处标 `[待填]` |
| 既有文献与缺口 | 自己的阅读笔记 | 点名本文对话的两三篇文献，不在引言里写综述 |
| 中图分类号 | 《中国图书馆分类法》 | 查出来再填，查不到标 `[待填]`，不猜 |

## 步骤

本 skill 的中文体例：摘要 200 到 300 字，关键词 3 到 5 个；正文自称"本文"，不用"我们"；一级标题用"一、二、三"，二级用"（一）（二）"，三级用阿拉伯数字加点；正文写"表1""图1"，不写"Table 1"；表注以"注："开头放在表下方，"资料来源："另起一行；引用著录按国标格式；英文摘要与中文摘要逐点对应，各句承担同一功能。

1. 最后写摘要，200 到 300 字，按五步走：问题、设计、数据、主结果（含大小与单位）、贡献。完成条件：摘要里没有引用、没有未解释的缩写，主结果同时给出数字与单位。
2. 定关键词与中图分类号：关键词 3 到 5 个，分类号从《中国图书馆分类法》查出后连同选取理由写进 `paper/clc_codes.md`。完成条件：标题页上每个分类号在该文件里都有对应说明。
3. 引言写五段：典型事实、问题、本文做什么、本文发现（含量级）、相对点名文献新增了什么。完成条件：每段首句说明该段的功能。
4. 写识别策略段：一句话说清识别假设，写清变异的来源，列出支持该假设的检验，点名能推翻结论的威胁。完成条件：审稿人能直接引用那句话去检验。
5. 机制段按机制分析写，不写中介效应结论：说明哪个中间变量应当变动、往哪个方向动，并在独立的表里报告。完成条件：段落点名中间变量与预期符号。
6. 局限段写三条局限，每条配一个"什么结果会推翻本文"。完成条件：没有一条局限不配否证条件。
7. 写投稿声明，各一句：数据可得性、预注册（设计需要时）、利益冲突、基金项目、伦理审批。完成条件：五项齐全，数据可得性措辞与刊物要求的那句一致。
8. 写逐条回复：先一页说明信，再按审稿人分段，原文照引（斜体）、回应、修改位置（第几节、第几页、第几行）。完成条件：每条意见编号恰好出现一次，每个位置在定稿 PDF 里都能找到。

## 验收

- [ ] 摘要落在刊物规定字数内（默认 200 到 300 字），且不含引用。
- [ ] 首页出现 3 到 5 个关键词与 1 到 2 个中图分类号，每个都在 `paper/clc_codes.md` 里有选取理由。
- [ ] 引言五段，每段首句说明该段的功能。
- [ ] 识别策略段写明假设、变异来源、支持检验与主要威胁。
- [ ] 局限段每条局限都配了否证条件。
- [ ] `paper/statements.md` 五项齐全，数据可得性措辞取自刊物要求。
- [ ] 回复信里每条意见都照引原文，并给出能在定稿 PDF 中定位的节、页、行。

## 常见失败模式

| 模式 | 表现 | 纠正 |
|---|---|---|
| 摘要先写、之后不回改 | 摘要描述的还是被删掉的设定 | 从最终的表倒着写摘要 |
| 贡献只有形容词没有对照文献 | 审稿人问相对那篇显然的前作新在哪 | 点名两三篇文献，一句话说清差别 |
| 机制段写成了中介效应结论 | 设计分不开渠道与代理变量 | 按机制分析报告中间变量，不宣称中介效应 |
| 声明段从别处套模板 | 数据可得性承诺了不能分享的数据 | 按实际的数据共享约定重写 |
| 回复信改了数字没改正文 | 回复引用的修改在稿子里找不到 | 正文与位置指针同一遍改完 |

## 与其它 skill 的接口

- 上游：`estimation` 提供量级；`tables-figures` 提供表图对应表与表注；`report` 提供 `values.json`。
- 下游：`review` 把已投出的稿件变成返修流程；`report` 的溯源文件用来回答投稿阶段的可复现性质询。

## 领域细节去哪查

- 能源与环境：`domains/energy-env/institutional.md` 取可直接引用的制度背景段；`domains/energy-env/pitfalls.md` 查引言需要预先化解的质疑。
- 劳动：`domains/labor/pitfalls.md` 查引言应当提前回答的审稿问题。
- 行为：`domains/behavioral/measures.md` 查实验里处理变量的构造与各自的隐含假设，这些写进设计小节。
