# 教学：硕士档

## 这一档的用法

硕士阶段要能改模板，不只是填模板。这需要四项具体能力：按自己的问题调整样本限制与变量定义，并说清调整改变了什么；判断识别策略能否扛住它最强的那条反对意见；跑通完整的复现包（replication package）；把结果讲到不越界。

改模板的意思是：读懂模板的假设，说出你的问题违反了哪一条，然后改掉依赖那一条的那一步。不是重写整套工序。工序的步骤序列在各档都一样，变的是你能自己辩护多少。

这一档的绑定能力是识别判断。你要能说出两三条会杀死这个设计的威胁，说出哪个稳健性检验（robustness checks）能抓住每一条，并事先知道什么结果会让你放弃这个题目。一篇报告了系数、列了五个稳健性检验、却没说明每个检验针对哪个威胁的硕士论文，还不算在做识别；那只是在证明软件能跑。

第二个交付物是复现包：原始数据或获取说明、一条命令从原始数据跑到最终表格的代码、陌生人能照着走的 README、以及表格与代码的对照表。复现包在别人机器上跑不起来，论文就不算完成。

## 该用哪些 skill

| skill | 什么时候用 | 这一档要注意什么 |
| feasibility | 定选题之前，检验数据与比较能不能承载这个问题 | 事先设好止损线：出现什么结果或数据问题就终止 |
| identification | 选设计，并在估计之前把它压测一遍 | 说出最强的替代解释，以及能把它区分开的那项检验 |
| data-prep | 构造分析样本，核对每一处限制 | 每处样本限制都是一个假设，写下来并检验其敏感性 |
| estimation | 跑基准回归、异质性分析（heterogeneity analysis），以及识别部分承诺过的检验 | 报全套设定，不只报赢的那个 |
| tables-figures | 产出论文真正引用的表和图 | 正文里的数字必须能追到某个表格单元 |
| report | 搭出让读者能重跑的复现包 | 一条命令、一份 README、一张表与代码的对照表 |
| writing | 讲清贡献，并把结果放进文献里 | 贡献来自识别与数据，不来自系数大小 |
| review | 投稿前把自己的稿子当审稿人读 | 模拟两位审稿人：一位攻设计，一位攻测量 |

## 不该做的事

1. 不要靠加控制变量解决内生性（endogeneity）。每加一个控制，估计目标就变一次，而处理后的控制变量会把结果推向一个你无法判断符号的方向；不带这个控制站不住的设计，带上也站不住。
2. 不要把稳健性检验当清单打勾。每个检验都在排除一个具体威胁；排除不了任何东西的检验只是给附录凑表，还会招来审稿人问你在藏什么。
3. 不要交一个只在你自己电脑上能跑的复现包。绝对路径、手工改数据、别人拿不到的数据文件，是最常见的三种失败；要在答辩前修好，不是答辩后。
4. 不要在表定稿之前写正文。围绕临时数字写出来的段落反正要重写，而重写正是数字开始对不上输出的时刻。
5. 不要把机制变量当控制变量。工时、职业、企业规模本身就是劳动论文所研究处理的后果；把它们放到方程右边，通常会把你要解释的那个效应吸收掉。
