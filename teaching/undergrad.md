# 教学：本科档

## 这一档的用法

本科阶段不需要自己设计研究工序。这一档的目标是：拿到一个问题，能在 skills 目录里找到与之匹配的模板，并且不改动模板逻辑地把它填完。模板就是产品，你的任务是用对一个。挑一个合适的，把占位符换成你自己的问题、样本和数据，从头到尾跑通。判断做完了没有，看模板自己的验收清单，不看结果漂不漂亮。

这一档里，识别策略（identification strategy）是一个概念，不是一项任务。你需要知道：任何实证结论都建立在一个比较上；比较要有处理组和对照组；论文必须说清谁是谁。你不需要为审稿人辩护一个设计，不需要自己构造工具变量，也不需要为自己的一篇论文做平行趋势检验。你需要能读懂已发表论文的识别部分，并在一句话里说出：拿什么和什么比。至于这个比较为什么站得住，知道有这么回事就够。

这一档最该练的其实是把需求说清楚。动数据之前写清五件事：一句话的问题、观测单位、结果变量及其精确定义、答案将依赖的那个比较、最后要交的文件。五件都在，模板就能执行；五件都没有，再先进的工具也执行不了。

## 该用哪些 skill

| skill | 什么时候用 | 这一档要注意什么 |
| feasibility | 选题之前，确认有没有可用的数据和可做的比较 | 你只是在查数据和比较存不存在，不是在证明设计可信 |
| identification | 读论文时，或被要求说出自己问题里的比较时 | 学会处理组、对照组的说法就够了；不要自己发明设计 |
| data-prep | 模板选定之后，把数据整理成模板要求的形状 | 逐字照模板的变量口径做；对原始数据做的每一处改动都写下来 |
| estimation | 跑模板指定的回归 | 先跑基准回归（baseline regression）；不要加模板没列出的控制变量 |
| tables-figures | 把输出变成模板要求的表和图 | 用模板的表格版式，写清它要求注明的项目 |
| report | 整理出能从原始数据重跑的工作文件夹 | 检验标准是同班同学能重跑，不是文件夹整齐 |
| writing | 描述你做了什么、结果说明了什么 | 只做描述，不主张贡献；报告估计值及其不确定性 |
| review | 只在读书会或评同学初稿时用 | 只评论表述和定义是否清楚，不评判设计能不能发表 |

## 不该做的事

1. 不要自己发明识别设计。一个你辩护不了的设计，扣分比一个照模板做对的少；模板不合适，就换问题，不要改设计。
2. 不要在跑完验收清单之前把回归输出当成结果。输出只是模板的证据，验收清单才是它成为交付物的条件。
3. 不要悄悄改模板的样本限制或变量定义。每处限制的改动都在改变那个比较，记下来，并且能说出为什么改。
4. 不要往正文里放你没算过的数字。缺统计量就写占位符然后继续；看起来合理但不在你输出里的数字，是之后补不回来的那类错误。
5. 不要只报跑出预期符号的那一个设定。把你跑过的设定都报出来，包括没跑通的和方向不对的，并说明它们各自显示了什么。
