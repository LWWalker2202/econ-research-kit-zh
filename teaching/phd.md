# 教学：博士档

## 这一档的用法

博士阶段动手的对象不是模板，是工序本身。问题不是"我怎么把这条流程用好"，而是"对这个题目来说，这个顺序对吗，哪一步该删、该挪、该加"。模板在每一步都编码了一个默认选择；你要知道每个默认为什么存在、领域的最佳实践什么时候已经走过了它、以及你的设计假设了哪些它没有假设的东西。

这一档与硕士档的差别有三处。第一是领域知识：你要熟悉到能看出一个变量测错了东西，能判断哪些改革是可信的外生冲击，而不只是方便可用。第二是审稿人视角：你按最苛刻且够格的审稿人读自己的初稿，在问题被提出之前先回答最强的异议。第三是可复现与投稿作为手艺：别人能跑的复现包、自己说清边界的论文、不吹过头的投稿信。

于是工序是一组可被重新设计的默认值，而不是要遵循的规程。问题需要预注册（pre-registration）就加上；可行性该是两周预实验而不是案头检查就换掉；估计环节该上规格曲线而不是五列表格就重建。skills 目录是这次重新设计的起点，不是天花板。

## 该用哪些 skill

| skill | 什么时候用 | 这一档要注意什么 |
| feasibility | 决定做还是不做，并设定约束整个项目的止损线 | 把预实验结论写下来；指不出来的可行性判断只是愿望 |
| identification | 针对最强的替代解释设计，而不是最方便的那个 | 把假设写成审稿人能证伪的形式，并说出能证伪它的检验 |
| data-prep | 建立数据来源、版本与精确的样本限制 | 每处限制都是审稿人会问的选择；在边界上做敏感性检验 |
| estimation | 跑设计所隐含的设定，加上能画出结果脆弱性的敏感性分析 | 脆弱性报告比偏好系数更重要 |
| tables-figures | 设定让论文可审计、而不只是好看的默认样式 | 不能从复现包重新生成的图只是装饰 |
| report | 产出陌生人能重建、核查者能审计的复现包 | 写明每项输入的来源与每个处理步骤的版本 |
| writing | 放好贡献，并写出你能辩护的局限 | 局限一节是你对自己知道什么的陈述，不是免责声明 |
| review | 投稿前模拟审稿意见，投稿后回应真实意见 | 按三位审稿人读：一位攻识别，一位攻测量，一位攻外部效度 |

## 不该做的事

1. 不要把工序当清单逐项打勾。这些步骤是用来重排、在该换的地方替换掉的；因为默认顺序在默认顺序上就照跑，正是这一档要纠正的失败。
2. 不要把识别委托给模板。模板编码的是别人关于哪个比较可信的假设；你自己说不出这条假设，这个设计就不是你的。
3. 不要让数据代替制度。测得很干净但意义错了的变量，给出的是对错误问题的高精度答案，再多稳健性检验也修不回来。
4. 不要不做审稿模拟就投稿。你给自己写的报告应当比你将收到的更狠；你没回应的异议会变成返修。
5. 不要发一个没在干净机器上重建过的复现包。在全新环境里的第一次运行是唯一算数的测试，它应当发生在投稿前，不是返修时。
6. 不要把局限一节写成仪式。如果你说不出在替代假设下估计值会是什么样，这个设计就还没做完。
