# 配套用书

这个目录里放了两份 PDF。整个仓库长成现在这个样子，源头就在这里，所以即使你不打算从头读到尾，也值得花五分钟看看它是什么。

## 这本书是什么

《经济学提示词工程指南》是一本写给本科、硕士、博士三个层次同时看的讲义。它用中文写，因为它处理的制度细节是中国的；当前版本 208 页。全书的主张只有一句：**不可验收的提示词不是规格，是许愿。** 剩下的篇幅，都是把这句话在经济学里展开。

书里有六十个模板。十二个通用（拆解复杂问题、压力测试研究想法、读论文结构、自审提示词）；三十个分支模板，按领域分组：微观实证、发展与田野实验、产业组织、贸易与空间、宏观与金融、公共经济学、行为与实验、经济史与文本、理论建模、写作与投稿；另外十八个是三个方向的深度模板：行为与实验、劳动、能源与环境。每个模板都是同一个八段式：适用场景、输入与输出、变量表、提示词正文、示例片段、常见反例、验收清单、来源。

## 该读哪一份

- `prompt-engineering-for-economists-v2.pdf` 是当前版本，读这一份。
- `prompt-engineering-for-economists-v1.pdf` 是第一版（170 页、42 个模板），留作存档：如果哪位读者引的页码对不上，原因在这里。

## 书和这个库的分工

它们回答的不是同一个问题，谁也替代不了谁。

- 书回答**为什么**和**怎么写**：为什么七个槽位就够描述一项任务、为什么一条答不了是或否的验收项就是写坏了的、怎么把一句模糊的请求变成一份规格。
- 库回答**跑什么**：八个工序目录、十二个领域包，而且每一道工序要么有能跑的模板加金样，要么有一个读你产出的检查器。

书里的六十个模板是任务模板。库把它们沿另一个轴切了一遍：书问"这是哪一类任务"，库问"你走到科研流程的哪一站"。十二个通用模板变成了 `skills/` 下的工序文件；分支模板变成了 `domains/` 下的领域包；十八个深度模板，正是三个方向先有自己领域包的原因。

## 哪一页配哪一道工序

| 你想做的事 | 书里读 | 然后用 |
|---|---|---|
| 把任务写清楚，别漏东西 | 第 2 章，七个槽位 | `skills/*/SKILL.md` 的输入一节 |
| 把经济学问题描述对 | 第 3 章，八个要素 | `skills/feasibility/`、`skills/identification/` |
| 要一份本领域的模板 | 第 5 章，按分支 | `domains/<你的领域>/` |
| 在行为实验、劳动、能源环境上走深 | 第 6 章 | `domains/behavioral/`、`domains/labor/`、`domains/energy-env/` |
| 判断一份产出到底行不行 | 第 8 章，六维量表 | 每道工序的 `## 验收` 清单 |
| 别编文献 | 第 9 章 | `domains/*/pitfalls.md` |

## 许可与引用

这本书是工作讲义，不是正式出版物，放在这里供参考和教学使用。引用写成：

> LW Walker，以及朋友们、家人们：《经济学提示词工程指南》第二版，2026 年。

如果你把某个模板用到教学材料里，请保留八段式和验收清单——最难写对的正是这个形状。
